# Day Plan 安卓桌面小组件

一个只读挂件：去拿你自己仓库里的 `widget.json`，把今天的课摊在桌面上。
不写入任何东西、不要登录、不含你的待办正文（除非你自己把发布范围调到 full）。

## 为什么要有它

安卓上想在桌面显示自定义内容，免费路子只有两条：系统日历小组件（看不到倒计时和天气），
或者 KWGT 的网页组件（要付费授权）。这个 App 就是第三条：**免费、能看倒计时和天气、样式自己定**。

## 怎么拿到安装包

本仓库用 GitHub Actions 云端构建，**你电脑上不需要装 Android Studio**：

1. 仓库页 → Actions → 「构建调试版 APK」 → Run workflow → Build。
2. 跑完（约 2～4 分钟）进这次运行记录，Artifacts 里下载 `dayplan-widget-debug`。
3. 解压得到 `app-debug.apk`，传到手机安装。

小米/红米装未签名包要**临时关掉「纯净模式」**并允许「安装未知应用」，装完可以再开回去。
调试包用的是 Android 自带的 debug 签名，卸载重装不需要额外操作。

## 配置

桌面长按 → 小组件 → 找到 Day Plan → 拖到桌面 → 弹出设置框，填你自己的快照地址，例如：

```
https://raw.githubusercontent.com/<你的账号>/<你的仓库>/main/widget-xxxx.json
```

每人一份：你的仓库、你的令牌、你的文件名，和别人互不可见（除了地址本身——见下）。

## 刷新

`updatePeriodMillis` 设的是 30 分钟，这是系统允许的最小值，再快也不会更快。
快照走的是 GitHub Pages / raw 的 CDN，最长还有约 10 分钟延迟，所以**改完课表别盯着桌面等**。

## 显示内容与隐私

卡片渲染的字段完全来自 `widget.json`，发布范围（lite / count / full）在你本地版「设置 → 发布到桌面小组件」里选。
`lite` 档含课程名与教室；`count` 档只报条数。**仓库是公开的，知道地址就能读到**，
所以建议把快照文件名换成猜不到的样子，别用默认的 `widget.json`。

## 卡片画的是什么

标题行「周三 · 农历九月初五」，副标题是现成的 `summary`（如「4 节课 · 2 件待办」），
下面最多 4 行课程（此刻正在上的那节用主题色描出来），再下面是倒计时（`next.text`），
最后一行天气（快照里 `wx.offline` 为真时会写明是多久之前的缓存）。

**过期保护**：如果快照的 `days` 里没有今天这一条，卡片只显示"快照是某日的，没更新"，
不拿旧的倒计时和天气糊弄人——这条逻辑与 `widget.html`、iOS 的 Scriptable 脚本三端一致。

点卡片会打开本地版 PWA。
